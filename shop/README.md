# 밀리언드림 쇼핑

기존 `shop/` 원본이 로컬 저장소와 배포 사이트에 없어, 2026-11-17에 새로 만든 정적 쇼핑 안내 화면입니다. `shop.js`가 `products.json`을 읽고 추천 상품, 상세, 장바구니 수량을 표시합니다. 장바구니는 이 브라우저의 `localStorage`에만 저장됩니다.

## 판매와 결제

상품 세 개는 [공식 래피드 판매 페이지](https://www.latpeed.com/products/SHXmi)에 확인된 실전반·코칭반 1·코칭반 3 옵션을 안내합니다. 가격과 할인·재고는 바뀔 수 있어 이 사이트에 저장하지 않았습니다. `checkout.html`은 장바구니를 보여주고 공식 판매 페이지로 이동시킵니다. 옵션은 판매 페이지에서 다시 선택해야 합니다. 이 사이트는 주문·결제·고객 정보를 받거나 결제 완료를 확인하지 않습니다. `complete.html`은 이를 설명하는 안내 페이지입니다.

## 공개 전 채울 정보

모든 공개 페이지 푸터의 상호, 대표, 사업자등록번호, 통신판매업 신고번호, 주소, 연락처 `[ ]`를 실제 정보로 바꿔야 합니다. 이메일은 기존 사이트에 공개된 주소를 유지했습니다.

## 파일

- `index.html`, `product.html`, `cart.html`, `checkout.html`, `complete.html`: 공개 쇼핑 화면
- `shop.css`: 밀리언드림 공통 색·서체를 쓰는 쇼핑 전용 스타일
- `shop.js`: 상품 표시, 장바구니 수량·저장
- `products.json`: 세 옵션의 안내 문구와 공식 판매 페이지 주소

별도의 `admin.html` 또는 `api/`는 만들지 않았습니다. 서버 주문·결제 기능이 없기 때문입니다.
